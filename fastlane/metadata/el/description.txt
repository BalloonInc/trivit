Το Trivit είναι μια πανέμορφα απλή εφαρμογή μετρητή που σας βοηθά να παρακολουθείτε τα πάντα στη ζωή σας. Είτε μετράτε συνήθειες, προπονήσεις, καθημερινούς στόχους ή αποθέματα, το Trivit το κάνει αβίαστο και ευχάριστο.

ΑΠΛΟ ΚΑΙ ΔΙΑΙΣΘΗΤΙΚΟ
Απλά πατήστε για να μετρήσετε. Χωρίς περίπλοκη ρύθμιση, χωρίς καμπύλη εκμάθησης. Δημιουργήστε έναν νέο μετρητή σε δευτερόλεπτα και ξεκινήστε να παρακολουθείτε αμέσως. Η καθαρή διεπαφή χωρίς περισπασμούς σας κρατά εστιασμένους σε αυτό που μετράει.

ΕΦΑΡΜΟΓΗ APPLE WATCH
Παρακολουθήστε τους μετρητές σας απευθείας από τον καρπό σας με την ολοκαίνουργια εφαρμογή Apple Watch. Οι μετρήσεις σας συγχρονίζονται αμέσως μεταξύ iPhone και Apple Watch, ώστε να είστε πάντα ενημερωμένοι ανεξάρτητα από τη συσκευή που χρησιμοποιείτε.

ΟΜΟΡΦΑ ΧΡΩΜΑΤΙΚΑ ΘΕΜΑΤΑ
Επιλέξτε από 8 ζωντανά χρωματικά θέματα για να εξατομικεύσετε τους μετρητές σας. Κάθε μετρητής αποκτά το δικό του ξεχωριστό χρώμα, καθιστώντας εύκολη την αναγνώριση με μια ματιά. Ο πολύχρωμος, επίπεδος σχεδιασμός είναι τόσο όμορφος όσο και λειτουργικός.

ΜΕΤΡΗΣΤΕ ΤΑ ΠΑΝΤΑ
- Καθημερινές συνήθειες και ρουτίνες
- Επαναλήψεις και σετ προπόνησης
- Απογραφές αποθεμάτων
- Τήρηση σκορ για παιχνίδια
- Παρατήρηση πουλιών ή άγριας ζωής
- Ποτήρια νερού που καταναλώθηκαν
- Βήματα προς έναν στόχο
- Οτιδήποτε άλλο χρειάζεται να μετρήσετε!

ΣΥΓΧΡΟΝΙΣΜΟΣ ΣΕ ΟΛΕΣ ΤΙΣ ΣΥΣΚΕΥΕΣ
Οι μετρητές σας συγχρονίζονται αυτόματα σε όλες τις συσκευές σας μέσω iCloud. Ξεκινήστε να μετράτε στο iPhone σας και συνεχίστε στο Apple Watch σας, ή αντίστροφα. Τα δεδομένα σας είναι πάντα μαζί σας.

ΠΡΟΤΕΡΑΙΟΤΗΤΑ ΣΤΟ ΑΠΟΡΡΗΤΟ
Τα δεδομένα σας παραμένουν στις συσκευές σας και στον προσωπικό σας λογαριασμό iCloud. Δεν συλλέγουμε προσωπικές πληροφορίες και δεν υπάρχουν αναλύσεις ή παρακολούθηση. Οι μετρήσεις σας είναι δική σας υπόθεση.

ΧΩΡΙΣ ΔΙΑΦΗΜΙΣΕΙΣ, ΧΩΡΙΣ ΣΥΝΔΡΟΜΕΣ
Το Trivit είναι εντελώς δωρεάν χωρίς διαφημίσεις, χωρίς αγορές εντός εφαρμογής και χωρίς συνδρομές. Απλά μια εξαιρετική εφαρμογή που κάνει αυτό που υπόσχεται.

ΑΝΟΙΧΤΟΥ ΚΩΔΙΚΑ
Το Trivit είναι ανοιχτού κώδικα! Μπορείτε να δείτε τον κώδικα, να προτείνετε βελτιώσεις ή να συνεισφέρετε στο GitHub στο https://github.com/BalloonInc/trivit-ios

Η έκδοση 5.0 είναι μια πλήρης επανεγγραφή με την τελευταία τεχνολογία SwiftUI της Apple, προσφέροντας βελτιωμένη απόδοση και εκλεπτυσμένη εμπειρία χρήστη, διατηρώντας παράλληλα την απλότητα που κάνει το Trivit εξαιρετικό.

Κατεβάστε το Trivit σήμερα και αρχίστε να μετράτε αυτό που σας ενδιαφέρει.
